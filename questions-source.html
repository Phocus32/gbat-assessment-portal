Bulk Upload Questions

Upload a question file instead of typing them one by one. Supported: .csv, .xlsx, .xls, .xlsm, .ods, .json, .tsv, .txt.

File format guide

CSV / Excel / TSV / TXT: The first row should be a header row with these columns:

question, optionA, optionB, optionC, optionD, answer, solution, svg

  • question — the question text (required).
  • optionA–optionD — the four answer choices (required).
  • answer — A, B, C or D (also accepts 1–4 or the exact option text).
  • solution — the step-by-step explanation shown to students.
  • svg — optional raw SVG code for a diagram.

JSON: An array of question objects, e.g.
[{"q":"...","options":["A","B","C","D"],"ans":0,"sol":"...","svg":"<svg...>"}]

For Word documents, save/export them as CSV first, then upload the CSV.
